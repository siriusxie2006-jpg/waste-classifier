# 下一步：先确定可信的基线

2026-11-10。本轮先检验现有结果的稳定性与不足，不新增网络结构，也不通过单张矿泉水瓶照片挑模型。

1. 核对固定划分与已经记录的重复/相似组，确认训练、验证、测试边界。
2. 对基线和现有增强候选分别比较 seed42、43、44；复用已完成的 seed42 两组，只新增四次训练。固定完整图片输入、ResNet18 单层头、3+7 轮、同样优化器和选模指标。
3. 比较六类 Macro-F1、逐类识别、塑料/玻璃双向混淆，以及亮度和模糊干扰下的表现。记录同一张验证图上谁答对、谁答错。
4. 报告均值与种子变化，判断候选收益是否稳定、是否牺牲某些类别。该实验仍使用同一验证集，不用于宣称手机实拍准确率。
5. 根据证据确定后续模型改进目标，再开展结构或学习目标的修改与消融。若纳入实拍开发数据，需预先固定用途与分组；已知反馈照片不作为独立最终测试。
