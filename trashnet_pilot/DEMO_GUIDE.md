# 本地演示使用说明

页面默认使用“基础 ResNet18”。上传单件垃圾的图片后自动识别。左侧可上传、恢复原图、裁剪、调整亮度和模糊，右侧紧邻显示预测与候选得分。

需要时打开“对比模型”或“显示关注区域”。对比以同一张图片和同一组调节参数运行另一份 ResNet18 权重。在“模型设置”中可以切换主结果所用的权重。类别说明和评分规则收在页面底部。

可点击“试用示例图片”体验操作；示例来自训练集，不用于证明模型泛化能力。调整滑块后图片和结果自动更新，“恢复原图”将亮度恢复到 1、模糊恢复到 0，并撤销手动裁剪。

## 类别和图片范围

六类显示为纸板、玻璃、金属、纸张、塑料、其他垃圾（数据集杂项类）。最后一类对应原数据集标签 trash，是模型学过的固定类别，不是“无法识别”。页面提供训练集中的实际例图，包括食品软包装、糖果包装、纸巾状纸团等；这一类与材质类别存在边界重叠，不能直接等同于国内垃圾投放四分类。

默认不自动裁剪：完整图片等比例缩放后，使用白色留边补成 224×224，主预览就是实际模型输入。模型仍需要固定尺寸的张量，但不需要为此裁掉图片边缘。

如需减少背景，点击“裁剪图片”，在原图上拖动框选，点击“应用裁剪”才生效；“使用完整图片”只撤销裁剪，“恢复原图”同时撤销裁剪和亮度、模糊调节。上传新图片时裁剪区域自动清空。裁剪后的预览、预测和热力图使用相同区域。框选组件由项目本地提供，不依赖外部裁剪服务。

单标签模型不会按各材质面积占比投票，也不会分别圈出图中的不同物品。拍摄用白纸背景不等于待识别的纸张垃圾。

如果待识别物品含有多种明显材质，或图片里有多个待识别物品，可以在“模型设置”中手动标记混合输入。程序会显示候选和人工确认提示，不会自动检测或分割物体。

## 得分和暂不能确定

主结果展示前三个候选，展开“全部类别得分”可查看六类分数，总和为 1。得分不是单张图片判断正确的概率保证，未知物品也可能得到很高的得分。

当前显示规则在以下任一条件下请求人工确认：用户标记混合输入；第一候选低于 70%；前两名相差不到 15 个百分点。这是尚未校准的演示提示规则，不是新的训练类别，也没有建立可靠的未知物体拒识能力。即使没有触发提示，也只显示“模型更倾向”，不声称判断确定。规则不改变模型权重、原始得分或验证指标。

## 热力图

打开“显示关注区域”后，热力图自动解释模型自己的第一候选，无需用户提供或选择类别。暖色表示对当前预测类别分数的正向贡献。热力图在预测后计算，不是材质分割或面积估计，也不能证明模型判断正确。

打开模型对比后，两份权重都接收相同的完整图片或用户框选区域。每张热力图解释对应模型的预测，标题会标明类别。

## 整图训练与误判

演示默认使用三个匹配 ResNet18 基线中普通验证 Macro-F1 最高的 seed43，整图增强对照使用相同种子。两份权重共享架构、完整图片预处理、六类标签及训练和验证划分。默认权重在 375 张验证图片上准确率为 93.33%，Macro-F1 为 0.9257。对照权重分别为 92.53% 和 0.9184。

用演示的 CPU 单图流程逐张复核，两份权重各复现了全部 375 张图的预测类别。与归档的批量评估相比，第一候选分数的最大差分别约为 0.28 和 0.15 个百分点。已知水瓶在默认权重下首选塑料，得分 43.8%，会提示人工确认。这张照片曾用于开发回查。[推理复核记录](outputs/baseline_demo_check.json)

上述选择用于单件垃圾的基础演示。此前冻结的保留集研究与三种子汇总见 [保留测试结果](HELDOUT_TEST_RESULTS.md)。手机实拍中的材质混淆仍是基础模型的局限。[整图增强训练结果](TRAINING_COVERAGE_RESULTS.md)

识别单个瓶子时，可以在“模型设置”中选择 **ResNet18（瓶类样本微调）**，再打开“对比模型”查看原基础 ResNet18 的结果。该权重在 28 张新保留瓶类裁图中认对 18 张，原基础版认对 7 张。普通验证上，微调版认对的金属样本少 5 张，通用默认使用基础版。 [第一阶段验收](BASELINE_MATERIAL_RESULTS.md)

## 更新和启动

在仓库根目录先按 [复现说明](README.md) 准备数据和模型权重，再从已安装依赖的 Python 环境启动：

```sh
python -m streamlit run trashnet_pilot/demo_app.py --server.address 127.0.0.1 --browser.gatherUsageStats false
```

装好基础版和整图增强版的权重后，可核对整条演示流程：

```sh
python trashnet_pilot/test_demo_clarity.py --app
python trashnet_pilot/test_image_framing.py
```
