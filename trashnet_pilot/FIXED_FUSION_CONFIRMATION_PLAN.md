# 固定双层融合的独立训练种子复核计划

2026-11-10。上一轮门控没有超过固定融合，门控方案维持失败结论。本轮明确另立固定融合的确认假设，不更改上一轮的原始规则或结果。

- 复用 seed42 的匹配强对照和固定融合；仅为两种结构各新增 seed43、44，共四次训练。
- 使用与初试完全相同的四个训练源文件、数据划分、完整图片输入、光照/模糊增强、类别加权、layer3＋layer4 微调范围、学习率和 3+7 轮预算。
- 每次仍按干净验证 Macro-F1 保存最佳权重；主要比较仍是亮度五条件平均 F1 与模糊三条件平均 F1 的均值。
- 预定确认标准：新增两个种子的配对干扰得分均为正；三种子平均增益至少 0.01；平均干净 F1 下降不超过 0.01；平均塑料召回下降不超过 0.02。若不通过，不追加种子或参数搜索。
- 同时列出已有 layer4 增强方案的三个种子表现，说明微调范围不同，作为性能背景而非单模块消融。
- 单独报告 seed43/44 均值，避免让被用于挑模型的 seed42 掩盖后续表现。

三种子仍使用同一验证图集，只能检查训练随机性，不能当作三份独立数据，也不能估计手机实拍准确率。反馈照片不用于本轮选择，保留测试集不评估，演示默认不自动替换。

计划会在训练前保存为 `outputs/fixed_fusion_confirmation_plan.json`。初试权重、历史预测与干扰结果均受指纹保护，脚本为 `run_fixed_fusion_confirmation.py`。下一步若稳定改善，仍需考虑容量相近分类头对照，明确增加参数和跨层信息各自可能的作用。
