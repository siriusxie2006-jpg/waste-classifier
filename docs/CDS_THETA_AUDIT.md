# CDS theta 与类别对覆盖统计

- 数据：E0 Train 256D 静态特征，1766 张；中心为归一化 embedding 的类均值。
- CDS 默认 theta：0.30。
- theta=0.30 激活：591/1766 = 33.47%；所选有序异类对 25/30。
- 每个 anchor 类的激活数：{"cardboard": 44, "glass": 128, "metal": 126, "paper": 132, "plastic": 109, "trash": 52}。
- 统计采用 prototype argmax（掩蔽真实类别）；该探针是固定 E0 特征上的 w=1 几何覆盖统计，不等同于训练时按 full-softmax p_b 加权的梯度贡献。
- 本轮重新生成的候选激活率：
  - theta=0.20: 797/1766 (45.13%)
  - theta=0.25: 694/1766 (39.30%)
  - theta=0.30: 591/1766 (33.47%)
  - theta=0.35: 510/1766 (28.88%)
  - theta=0.40: 425/1766 (24.07%)
